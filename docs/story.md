# 项目故事：让工业几何简化具备可检查的接受条件

## 一句话

BS2Quad 从 NURBS 中恢复解析结构，再用独立的完整参数域距离上界和拓扑验收，决定这张面能否安全替换。

## 冲突

船舶模型中的圆柱、圆锥和球面可能被保存为统一的 NURBS 表示。后续操作承担了复杂表达的成本。但把采样点拟合得很近，不足以说明整张面可替换：狭窄凸起可以躲过采样，周期接缝可以在换参数后断开，退化极点可能在修复中丢失。

## 洞察

候选生成和结果验收应当分开。成熟内核可以快速给出解析候选，原有有理样条的控制网则提供另一条证据路径：通过区间插结和 Bernstein 凸包性质，对整个参数域的隐式残差给出上界，而不是继续增加均匀采样密度。拓扑变化也需要独立检查，不能让一个很小的支撑面误差代替边界与连续性。

## 方案

输入检查 → 解析候选恢复 → 原样条全域距离上界 → 深复制裁剪面 → 重建参数曲线/周期接缝/极点 → 有效性、面积、边界、双向裁剪区域和法向验收 → 指定邻面 G1 → 发布结果或返回明确拒绝。

内核负责候选，独立算法负责支撑面误差界；有限点拟合与连续曲面证明使用不同接口。失败时保留原输入，批处理继续处理下一张面。

## 证据

本次证据分别回答三个问题：窄凸起、非夹持端点和周期重数能否击穿误差证明；50–200 控制点的 1000 例混合输入能否正确处理并保持一致；转换后的同一有限裁剪面在投影、求交和布尔运算中是否获得真实收益。所有结果均保留原始数据，性能未达标项不并入成功结论。

## 愿景

下一阶段首先补上 SGK 1.7 实机集成，复用同一套反例与原始记录流程；然后完善边界和 G1 的连续误差界、近圆锥的更紧上界、装配级事务替换及真实船舶模型验证。当前在线数值路径不依赖大模型推理，10 ms 判定预算由可复现的 C++ 几何计算承担。
