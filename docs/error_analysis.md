# 误差来源与适用范围

## 已处理的误差路径

1. 原生成器把曲面采样点当作等权控制点，得到的不是精确圆柱/球面。当前正例来自真实解析面的有理 NURBS 表示，插结保持几何；独立隐式残差和已知参数测试核对真值。
2. 有限均匀采样会漏掉窄凸起。支撑面验收加入完整参数域 Bernstein 残差界，采样统计仅作诊断。
3. 非夹持高端点若错误地把插结跨度强制为最后控制点下标，会丢掉末控制点贡献。固定 cubic 反例在原内核端点高度为 `0.01/6 mm`，旧证书却给出 0；回归要求证书必须包围原内核求值。
4. 异常、空投影和无有效样点不能形成零误差。未知指标保留无穷值，JSON 为 `null`，验收失败。
5. 不同参数化不能在相同 `(u,v)` 上比较法向。当前投影到同一空间位置，处理位置变换、周期等价参数和面方向；邻面按题目字面采用有向法向夹角。
6. 默认固定面积积分会对有理圆柱和圆环面产生偏差。裁剪面积验收及 CAD 对比使用 `Eps=1e-10` 的自适应积分；面积仍是附加数值检查，不冒充连续边界证明。
7. OCCT 的通用点到面的极值接口在本次转换圆环上出现高估：已在支撑面且位于裁剪域内的点仍报告约 `0.31 mm` 距离。受控基准使用同一套有限域算法比较前后：完整边界最小距离加周期映射后的全部支撑投影，并用已知法向偏移距离核验。原失败记录保留。
8. 点拟合中的坐标归一化可能掩盖世界坐标舍入。当前验收真正构造的世界坐标几何；`1e12` 平移下不可精确表示的球心反例会拒绝，而不是继承归一化空间中的小残差。

## 证书为何可能保守

Bernstein 系数凸包、区间运算和正权重最小值相乘会放大上界。圆锥使用 `sqrt(|F|)` 可在顶点附近保持正确，但在远离顶点的近圆锥上可能过松。证书通过是充分条件；证书不通过不等于数学上不存在合格解析表达。

当前次数上限为 12，环状圆环要求 `R>r>0`。算术溢出或低权重导致无法得到可靠界时直接拒绝。完整域证书针对原始支撑面到解析支撑面的单向距离，不证明反向覆盖、拓扑同胚或法向场的全域误差。

## 尚未完成的保证

- 边界 Hausdorff、裁剪内部和 G1 当前是有限采样加内核一致性检查；尚无连续域全局误差证书。
- 1000 例为可复现合成数据，不代表全部船舶工业模型，也不证明任意次数/权重组合都满足 10 ms。
- CAD 加速依赖具体曲面、裁剪、查询和后端。未达到 50% 的操作必须保留；不能以求交收益代替投影或布尔收益。
- 有限点拟合可能拒绝极端病态或不足以确定类型的局部点集，不保证完整识别召回率。
- ASan/UBSan 和 Valgrind 的实际运行范围见实验报告，不能由一次无崩溃推断所有第三方路径均无泄漏。
- SGK 1.7、装配级事务替换及真实船舶数据尚未验收。

## 后续优化

优先完成 SGK 实机适配和真实模型回放；以有界自适应细分收紧近圆锥证书，并为边界和法向导数建立连续误差界。随后分析圆环布尔运算中边界几何与拓扑成本，分别报告“支撑面恢复”与“完整 CAD 操作”的收益。每项优化都要保留相同输入、强基线和负例。
