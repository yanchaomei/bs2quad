## 全域距离证书的数学复核

证书针对完整原始参数域，给出从源 NURBS 到目标解析支撑面的**单向距离上界**。它没有用采样最大值代替连续域上界。

1. **原始表示与分解。** 从原始正权有理控制点建立区间齐次坐标。周期表示采用 OCCT 的操作性展开节点序列及循环齐次控制点。插结在区间运算内执行，将有效域内节点升至所需重数，再抽取非空 Bézier 跨度；未用拟合曲面替换原始几何。
2. **高端点插结。** 最终实现取现有节点的实际最右索引。先前在未夹持有效域高端点强制使用 `k=n` 会漏掉最后一个控制点的混合项，破坏源几何；该问题已经修复，并有直接比较原始内核高端点高度与证书上界的回归。
3. **Bernstein 乘积。** 双参数乘积使用对应二项式系数比例。对角项只计一次，非对角对称项合并为两倍权重；二者具有相同精确权重，区间乘以 2 仍包围原始两项之和。缓存仅含次数决定的权重及输出索引，不缓存输入几何或验收结果。
4. **非负权重乘法优化。** 第二操作数非负时，分别按第一操作数非负、非正和跨零选择乘积端点。这些端点是矩形区间乘积的真实极值，随后仍向外舍入；其余情况保留四端点公式。
5. **有理分母。** 每块齐次权重的严格正下界用于控制分母幂次。非正权重包围、溢出及其他无效运算均令证书不可用，不能变成零误差。

各解析类型的残差到距离转换符合保守上界要求：

| 目标类型 | 已核对的距离上界依据 |
| --- | --- |
| 平面 | 单位法向的线性残差绝对值即支撑面距离。 |
| 球面、圆柱面 | 平方半径残差分解后的距离分母至少为半径，因此除以半径给出保守上界。 |
| 圆锥面 | 对非负量使用 `(A-B)^2 <= abs(A^2-B^2)`，取平方根可覆盖包含锥顶的完整解析支撑面。 |
| 环状圆环面 | 四次隐式残差的因式分解给出分母 `r * (R^2-r^2)`；要求 `R > r > 0`。 |

圆锥的正弦、余弦由向外舍入的 Taylor 运算和余项包围获得，已移除“普通 libm 结果扩展若干 ULP 即可视为证明”的前提。构建显式关闭不安全浮点重排和乘加收缩。次数预算、正权及环状圆环面的限制属于当前证书适用条件；不满足条件时必须明确拒绝或报告证书不可用。
