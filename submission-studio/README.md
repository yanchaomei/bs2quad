## 配音与验收范围

配音使用本机 macOS `say` 的 Tingting 声线，速率175。音频、文本、配置和样音保留，无在线付费服务。每段使用自然生成时长，只加前后静音，不变速、不截断；工具检查每段可以放入场景。`audio-integrity.json` 比对最终 PCM 中每一段与原始音频完全相同。

已经检查音视频流、时长、完整解码与全部场景关键帧。主观自然度、逐字发音及精确口型/字幕听觉同步没有获得独立人工确认，不能把这些未核事项标作通过。字幕以文字长度比例分段，不是语音强制对齐。

## 可编辑源与重建

`content/` 保留正文和指南，`scenes.json` 保存逐场景动作、观察、证据和旁白。`scripts/` 是材料制作入口。文档和图形生成在本地，所有几何运行和辅助几何求值编译在远程执行。

- `prepare_media.py --font <中文字体>`：从原始结果绘图，在有 macOS `say` 的机器重新生成离线旁白；需要 numpy、matplotlib、Pillow 和 ffmpeg/ffprobe。
- `render_documents.py --font <中文字体>`：需要 reportlab，生成两份 PDF。它会从根目录已冻结文档和场景重建可编辑正文。
- `render_video.py --font <中文字体> --mono-font <等宽字体>`：需要 Pillow 和 ffmpeg，重绘原始事件并合成视频。已生成音频可直接离线使用，不必重新调用语音服务。
- `capture_demo.py --help`：在远程捕获实际运行，拒绝复用已有输出目录；按新环境传入路径和容器参数。

本次生成器/环境版本见 `evidence/material-environment.json`。重建只重建材料，不自动重跑主实验；任何新增实验应另保存源版本及原始回执。
