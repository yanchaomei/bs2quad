# BS2Quad 详细作品说明

## 一、任务、使用场景与交付状态

船舶设计人员在大型装配中反复进行投影、求交和布尔操作。输入虽然以 NURBS 保存，其中仍可能包含圆柱、球面等解析结构。本项目先恢复解析候选，再检查该输入是否满足替换条件，避免只凭拟合样点的小误差作接受决定。

本轮目标是提供可复现的 C++ 实现、测试与原始证据。在线路径是确定性几何计算；没有在运行时接入大模型。成熟候选恢复来自 OCCT，本项目工程增量是独立距离界、裁剪与方向验收、成本控制和可追溯结果。尚未完成系统文献查新，不宣称方法首创。

## 二、算法与工程设计


### 需求与实现边界

目标是识别可等效的 NURBS 支撑面，恢复解析表达，再验证裁剪面是否可替换。默认距离容差为 `1e-5 mm`，边界阈值独立固定为 `1e-5 mm`，有向法向夹角阈值为 `0.1°`。题面 `1.e5` 按更严格的 `1.e-5` 实现；最终口径以命题方为准。

覆盖平面、圆柱、圆锥、球面和环状圆环面。圆环面保留在原有 `QuadricType` 枚举中，但不将其称作数学上的一般二次曲面。

| 赛题要求 | 实现路径 | 验收依据 |
|---|---|---|
| 判定与转换 | 内核候选恢复，独立距离验收，深复制拓扑重建 | 正例/负例、位置变化、部分面、完整闭面、周期与非夹持样条 |
| 最大与平均距离 | 原始样条完整参数域的单向支撑面距离上界 | 区间/Bernstein 充分条件；诊断采样单独保存 |
| 边界 Hausdorff | 原边界对应的新参数曲线及双向边界并集距离 | 有限边界采样到完整目标边的距离，属于采样验收 |
| 相邻 G1 | 指定真实邻面和原共享边，在同一空间位置比较有向法向 | 33 个共享边样点；超过 0.1° 拒绝 |
| 10 ms 判定 | 候选恢复及完整域距离验收，独立记录计时边界 | 50–200 控制点的固定配方与逐例最大值；不含读写、生成、后续 CAD 操作及拓扑重建 |
| 三类 CAD 耗时降低 50% | 同一有限裁剪域和相同输入，检查输出后比较 | 预热、交替顺序、5/7 次原始耗时与中位数；未达标项单列 |
| C++ 与 SGK 1.7 | 当前 C++17/OCCT 7.7.0，SGK 无模拟适配 | SGK 1.7 目标构建和运行仍未完成 |
| 连续处理与异常 | 串行批处理、错误关闭、原输入保留、输出写入检查 | 1000 例重复运行、损坏文件/非法参数/写失败、ASan/UBSan/Valgrind 实际范围 |

完整域支撑面距离证书不会自动变成连续边界或 G1 证书。每个检查分别记录是否执行、是否完整、误差和结果，未执行量使用无穷值，JSON 输出为 `null`。

### 处理流程

```mermaid
flowchart LR
  A[验证 NURBS 输入] --> B[OCCT 恢复解析候选]
  B --> C[独立完整域距离上界]
  C --> D[深复制裁剪拓扑]
  D --> E[新参数曲线 接缝 极点]
  E --> F[有效性 面积 边界 裁剪区域 法向]
  F --> G[指定邻面 G1]
  G --> H[发布转换结果]
  C -->|失败| R[返回明确拒绝 保留原输入]
  F -->|失败| R
  G -->|失败| R
```

仅有支撑面输入时，执行到支撑面验收，不生成虚构边界或邻面结果。CLI 单面文件入口无法推断装配邻接，应由 C++ 调用方提供要求 G1 的邻面；锐边不是要求平滑的邻面。

### 候选恢复

OCCT `GeomConvert_SurfToAnaSurf` 根据原曲面的几何结构恢复解析候选，支持按目标类型调用。该成熟能力被明确归属于依赖内核。内核 gap 和类型候选都不能绕过独立验收。

数据入口检查空对象、非有限控制点、非正/非有限权重、无效节点和参数域。内核异常保留失败类别，不能被转译为“该面已经被证明不是解析面”。

### 完整参数域距离上界

将有理张量积样条写为齐次坐标 `S=(X/W,Y/W,Z/W)`。对原控制网做区间包围的精确插结，内部节点提高到次数重数，得到每个活跃跨度对应的有理 Bézier 控制网。周期基使用内核实际展开节点序列及循环控制点；非夹持端点使用真实节点位置，保留最后一个参与插值的控制点。

设解析面的齐次隐式残差分子为 `P(X,Y,Z,W)`，空间代数次数为 `m`。Bernstein 凸包性质给出 `|P| ≤ M`，其中 `M` 为全部系数区间端点绝对值的最大值。正权重满足 `W ≥ w_min > 0`，因此隐式残差绝对值不超过 `M / w_min^m`。

转换到几何距离的充分上界：

| 类型 | 残差 | 几何距离上界 |
|---|---|---|
| 平面 | 单位法向 `n·(p-c)` | 残差绝对值 |
| 球面 | `||p-c||²-r²` | `|F|/r` |
| 圆柱 | `rho²-r²` | `|F|/r` |
| 圆锥 | `cos²(a)*rho²-(r*cos(a)+z*sin(a))²` | `sqrt(|F|)`，含顶点仍保守 |
| 环状圆环 | `(rho²+z²+R²-r²)²-4R²*rho²` | `|F|/[r*(R²-r²)]`，要求 `R>r>0` |

实际计算在解析原点附近进行，法向/轴向系数也使用区间归一化。每一步算术向外舍入；圆锥三角系数由区间 Taylor 展开和余项包围。溢出、无效分母、超出次数预算或不能构造上界时拒绝发证。当前次数预算上限为 12。

完整域最大距离界不超过 `d` 时，任何归一化非负权重下的平均距离也不超过 `d`。输出的 `avgDistance` 仍仅是均匀参数采样诊断均值，未冒充面积加权实测均值。

### 保持证明条件的性能优化

Bernstein 乘积权重只依赖次数，按次数缓存其区间包围和输出下标，不缓存输入几何或先前判定。平方中的非对角对称项具有同一精确系数，合并为带 `2` 倍权重的一项，减少重复区间运算。对角项只计算一次。该优化不减少采样、不缩小验证域、不放宽阈值。

缓存是线程局部的；同一转换器的统计状态仍要求单线程使用。实际冷启动、输入生成与操作范围由原始记录说明，不使用后续 CAD 计时填充判定耗时。

### 裁剪与邻面

深复制输入拓扑后识别局部支撑几何，保留位置变换。解析参数框架对齐原接缝，法向在对应空间位置比较。给复制后的边建立新参数曲线，并检查周期边两个方向；极点退化边根据有序相邻参数曲线恢复其角区间，接缝修复后重新映射极点区间。

结果必须通过拓扑有效性、边/环数量、边和顶点容差、自适应面积比较、双向裁剪内部覆盖、双向边界并集距离及有向法向保持。修复后的拓扑面和返回的支撑面都采用输入对应的世界坐标。

指定邻面必须与输入面共享实际拓扑边，且不能是输入面自身。沿原共享边确认两面的支撑和边界对应后，以面方向确定的有向法向比较角度。反向的 180° 不能取绝对点积后变成 0°。

### 稳定性、接口与测试

公开验收位置是 `Convert/ConvertBatch`、`ValidateAccuracy`、邻面检查、各 fitter 以及 CLI。有限点拟合独立使用归一化、秩与主元检查、代数初值与有界几何迭代；接受前对真正存储的世界坐标几何再次检查最大残差。有限点拟合不对点间曲面发证。

回归包含躲过采样列的窄凸起、非夹持高端点丢控制点、周期低重数、位置/参数化变化、完整球面极点、边界多孔、错误法向、重复点/共线点、超大世界坐标舍入、无效输入、空布尔结果和缓冲写失败。完整验收脚本同时检查保存回执、测试数量和性能标志，不把“执行结束”当作“指标通过”。

### SGK 集成清单

取得真实 SGK 1.7 SDK 和许可后，依次完成初始化/释放、NURBS 数组与位置提取、解析几何构造、裁剪边与参数曲线更新、投影/求交/布尔、错误映射以及目标编译链接。先跑现有反例，再跑同一 1000 例与真实船舶面，最后重测三类操作。只有这些回执齐备后才将兼容性状态改为通过。

### 误差分析、不足与下一步

区间 Bernstein 残差界独立于候选内核的 gap，减少采样漏检；其充分条件可能保守拒绝接近圆锥的可转换面。次数上限 12，环面限 `R>r>0`。边界/G1 仍需连续域界，装配事务替换与真实船舶模型尚未验证。部分点云可能病态，算法安全拒绝不代表几何上不存在解。

## 六、距离界为什么可以作为接受条件

### 6.1 从采样统计到逐点上界

原始曲面点到目标解析支撑面的距离记为 D(u,v)。诊断采样只能计算有限位置的 D，无法直接推出所有参数位置都不超限。本项目要求一个覆盖原参数域的数值 B，使每个有效 (u,v) 都满足 D(u,v)≤B，再以 B≤d 决定接受。候选类型、内核 gap、样点均值和独立 B 记录在不同位置，任何一个都不能替代其他对象的验收。

齐次表示使有理分母与多项式分子分开处理。对每个分解后的 Bézier 参数块，设源坐标为 X/W、Y/W、Z/W，权重严格为正；解析隐式函数 F 的空间代数次数为 m。把残差乘以 W 的 m 次幂，得到参数域多项式 P。正的 Bernstein 基函数在块内和为一，因此 P 的值位于所有系数的凸包内。系数本身用区间包围后，取所有端点绝对值的最大值 M，即可得到 |P|≤M。

同理，W 不小于该块全部权重下端点的最小值 w_min。只有 w_min>0 时才能安全除以其幂，得到 |F|≤M/w_min^m。每一块分别形成上界，再取最大值覆盖原参数域。块间边界不能被跳过；周期展开和未夹持端点也必须对应原输入。

![有限采样与完整域上界的区别。AI机制示意；图中的区间只是原理说明，不是实际残差曲线。](../assets/certificate.png)

### 6.2 五类残差如何转换成几何距离

平面采用单位法向，线性残差的绝对值就是点到平面的距离。球面令 q 为点到球心的距离，则 |q-r|=|q²-r²|/(q+r)，分母至少为 r。圆柱面用点到轴的径向距离代替 q，推导相同。使用 |F|/r 是保守上界，不需要把小代数残差直接当作小几何误差。

圆锥在轴向与径向组成的二维截面中表示。令 A=ρ cos(a)，B=r cos(a)+z sin(a)，对 A≥0 有 (A-|B|)²≤|A²-B²|，因此 sqrt(|F|) 可控制包含锥顶的解析支撑距离。顶点附近不采用除以梯度范数的公式，以免分母接近零。这个界也可能偏松，不能把证书拒绝理解为数学上不存在合格圆锥。

环状圆环面令 q=sqrt((ρ-R)²+z²)，几何距离为 |q-r|。其四次隐式残差可以分解为 (q²-r²) 与 ((ρ+R)²+z²-r²) 的乘积。在 R>r>0 时，第二因子不小于 R²-r²，且 q+r≥r，因此距离不超过 |F|/[r*(R²-r²)]。当前实现只对这个环状条件发证，不能推广到角环、纺锤环或退化半径。

### 6.3 舍入、分解和资源前提

实现从原始控制网构造区间齐次量，每步运算向外舍入，不假设普通浮点结果恰好等于真实值。圆锥三角系数使用带余项的区间展开。构建关闭不安全浮点重排与乘加收缩，避免编译选项破坏证明前提。区间包围失败、权重下界非正或溢出时，证书不可用；未知值不变成零。

当前次数预算为12，并有正权重与目标类型限制。次数缓存只保存与度数有关的权重和下标，不保存某个输入的判定。平方中的两个非对角项具有相同精确系数，合并成两倍权重仍向外包围。优化前后的数学条件不因10毫秒目标放宽。

逐点上界还意味着任何归一化非负权重下的平均距离不超过同一上界。报告中的 avgDistance 仍是诊断采样均值，既不是连续域真实最大值，也不是经过面积积分得到的实测均值。支撑面上界没有证明有限裁剪区域反向覆盖。

## 七、两个必须保留的几何反例

### 7.1 采样之间的窄凸起

固定回归的参数节点包含0.4001、0.40015、0.4002，中间控制高度为0.01毫米，形成很窄的线性突起。均匀采样列可能全部落在突起外，给出接近零的诊断误差；在参数0.40015处，原曲面实际高度为0.01毫米，已超过默认容差。

正确行为是独立上界反映该突起并拒绝接受。此反例检查“能否阻止错误接受”，不属于主1000例集合的额外成功样本，不能混入它的834/166分类统计。机制图描述的是缺陷漏检，不使用可能混淆类别定义的阳性/阴性术语。

### 7.2 非夹持端点不能丢掉控制点

非夹持样条的有效域端点不一定对应简单的首尾控制点复制。研发中曾在高端插结时强制使用最后控制点下标，遗漏真实参与端点求值的项，结果错误地给出零界。原内核在该点的高度为0.01/6毫米，足以否定这张零误差证书。

修复使用真实节点最右位置，回归直接比较原始内核端点值与证书包围关系。这个案例说明：证书不仅要检查不等式，还必须确认被证明的对象就是原输入，不能在分解时悄悄改变几何。

## 八、为什么支撑面相同还不能直接替换

### 8.1 支撑、边界、覆盖与方向是不同对象

同一圆柱支撑面上可以有不同外环、额外内孔和互补裁剪区域。即使源到目标支撑距离为零，删掉内孔或选错周期参数窗口仍会改变零件。原面翻转也可能保持点集不变，却改变用于后续操作的有向法向。

![同支撑面上的孔、方向和真实邻接。AI机制示意，不代表本轮每项都已获得连续域证明。](../assets/topology.png)

本实现按拓扑有效性、边环数量、边和顶点容差、面积、双向裁剪内部、边界和法向依次拒绝错误结果。面积是附加检查：相同面积不推出同一裁剪域，相同边界也不自动推出选取了同一内部。所有检查完成后才发布复制后的面，原输入不被原地替换。

### 8.2 边界并集距离的正确聚合

对源边界上一个采样点，先计算它到目标全部边的最小距离；再在源采样点上取最大值。反向同样计算，最后取两向最大。不能对每对源边和目标边直接取最大距离，否则同一矩形的相对边也会被错误算成不一致。

本轮每条普通边取33个样本，并计入修剪端点；点到目标边的距离由完整边对象计算。由于源边仍是有限采样，这不是连续Hausdorff的数学证书。边界门槛固定为1e-5毫米，不随调用方放宽支撑面容差一起放宽。

### 8.3 邻接不能由几何接近推断

两个面靠得很近不代表共享一条拓扑边。带邻面的接口先要求真实共享输入边，再沿该参考边检查空间对应与有向法向。若调用方只提供一个孤立面，程序不能替调用方虚构邻面检查已经通过。

题面用法向夹角规定0.1度门槛，因此反向180度不能通过取点积绝对值变成0度。设计锐边也不应被作为必须平滑的邻面传入；折角反例应得到拒绝，正向共面或真正光滑邻面才按约定接受。当前法向场依旧有限采样。

## 九、接口字段、状态与一次真实执行

### 9.1 调用方应该先检查什么

调用方必须先检查success、error和message，再使用几何结果。支撑距离、边界、法向和邻接都有独立的是否执行标志；validationComplete描述所请求检查是否完成，meetsRequirements描述数值是否符合门槛。未知量为无穷值，JSON中使用null。

| 输入形式 | 可请求的检查 | 不应自动作出的结论 |
|---|---|---|
| NURBS支撑面 | 恢复候选、完整域距离界、采样统计 | 已有边界或邻面G1证据 |
| 单个裁剪面 | 加上重建、边界、覆盖、方向等验收 | 已完成多面装配替换 |
| 裁剪面与真实邻面 | 额外检查原共享边上的指定邻面 | 任意未传入邻面都已检查 |
| 有限点集合 | 指定解析族的有限点拟合与最大残差 | 点之间的连续曲面已被证明 |

### 9.2 成功案例的两个时间

新录制的圆柱文件操作输出decision_ms为1.226066，conversion_ms为67.612869，源到解析支撑的界约2.543e-13毫米；adjacency_checked为false。这些字段来自真实报告，不能用其中的1.23毫秒表示包含拓扑重建的完整操作，也不能用它替代主1000例的分布。

旁边的几何预览是对实际BRep求值后绘制的网格；视觉重合不是数值验收。视频展示的远程进程时间还包含容器启动与文件读写，与程序内部两个计时字段也不是同一个指标。

### 9.3 明确拒绝、异常与批处理

自由曲面案例返回success=false和退出码1，是预期的业务拒绝。文件损坏、参数越界、输入输出别名和写入失败属于错误路径，CLI退出码2。任何未知误差不能被填成0来制造成功；批处理保留单项失败并继续后面的输入。

输入、输出和报告必须指向不同文件，包括父目录符号链接形成的别名。报告完成写入后还要检查缓冲区刷新和关闭；只有打开文件成功不足以证明最终字节已经落下。当前接口不是跨文件事务发布系统，这类更高层事务能力仍需工程集成明确设计。

## 十、如何解释测试覆盖与性能证据

### 10.1 三种数据不要混成一个准确率

主1000例来自固定配方的精确解析正例与自由曲面反例，包含姿态和控制点变化。针对性回归使用为某种错误精心构造的反例。真实工业模型则可能有不同的权重、次数、容差、损坏模式和邻接结构，目前尚未取得并验收。

因此，主集合的零错误接受/拒绝只能描述这组保存的数据；64个测试通过证明对应契约和断言得到预期处理，不能推出所有接口行覆盖或所有船舶模型识别率。测试数、CTest组数、逐例转换次数也不能相加后称为更多不同曲面。

### 10.2 判定预算的测量边界

50到200是逐例读取实际控制网的总点数，包含50、100、196和200，不是只靠请求参数推测。decisionTime使用单调时钟，覆盖候选恢复、诊断采样和独立距离验收。输入生成、文件读写、裁剪重建和后续CAD操作不在这个预算中。

本轮平均2.040974毫秒、P95为7.594653毫秒、最大8.247364毫秒。机器是共享的远程CPU环境，未宣称跨机器上限、最坏情况复杂度或严格实时调度保证。内存工具插桩下的耗时不参与10毫秒结论。早期跨版本优化结果保留为过程观测，严格单因素消融尚待完成。

### 10.3 CAD结果必须有效再比较耗时

前后必须使用同一有限裁剪域、同一查询点或操作数。空交集或失败操作可能很快，但没有完成同一任务。当前基准先检查非空、有效性与几何对应，再统计不含检查成本的运算时间；每组一次预热、五次正式运行，前后顺序交替。

求交五类均达到50%，投影只有一类，布尔有三类；六项未达到不能被其他操作平均掉。只有一张确定性部分面及有限查询的结果，不能用于保证所有CAD模型或SGK后端的收益。接近50%的组尤其需要目标机器与真实模型复测。

## 十一、资源生命周期、集成与后续验证

### 11.1 内存工具的结论范围

核心转换的ASan/UBSan千例和Valgrind检查通过，Valgrind仍有16字节可达分配而丢失分配与错误为零。完整STEP出口则在进程退出报告2964字节、138次分配，整组插桩测试失败。这两类结果不能互相抵消。

纯OCCT程序在不初始化STEP时无报告，只初始化为2916/136，导出1、10和100次均为2964/138。这定位了依赖初始化与首次传输路径，但有限重复没有增长不代表完全无泄漏，也不证明其他工作负载不会增长。公开清理尝试没有解决，材料保留原始失败。

### 11.2 SGK迁移必须取得哪些回执

先取得真实1.7版本SDK，确认初始化和释放、NURBS控制网与世界位置读取、五类解析对象构造。再适配裁剪边和参数曲线、周期与退化边、投影/求交/布尔以及错误映射。类型名相似不意味着语义和容差约定相同。

第一阶段只跑最小解析正例和损坏输入；第二阶段复跑窄凸起、端点、孔和方向反例；第三阶段运行保存的1000例与真实船舶邻接数据；最后重新测量三类CAD操作。只有实际构建、运行和回读记录齐备，才能更改sgk_1_7_verified标志。

### 11.3 优化优先级与停止条件

优先修复目标内核兼容性和已知失败，再改善性能。近锥顶证书的保守性可以考虑有界自适应分块，但必须保留正确包围和明确资源上限。连续边界及法向导数界是单独研究任务，不能沿用当前支撑界的成绩。

任何优化都固定输入、后端与容差，正确性或拒绝行为改变就停止性能比较并定位原因。无法取得真实SDK、无法确认结果有效或缺少原始输出时，保留未验证状态。材料制作、包校验、私有推送、正式提交和组委会接受分别记录。

## 十二、有限点拟合与裁剪实现的源码核对附录

# 技术附录：有限点拟合、裁剪面重建与回归真值

本附录依据当前源码快照 `200f7c7` 静态核对编写，未新增运行几何测试。文中“已有回归”指代码中存在相应输入与断言，不能代替最终证据包中的运行日志。当前实现依赖 OpenCASCADE；没有 SGK 适配与验收证据。五类目标是平面、球面、圆柱、圆锥和圆环面，其中一般圆环面属于四次解析曲面。

### 一、接口分层与发布条件

`include/BS2QuadCore.h` 提供支撑面、拓扑面、带切向邻面的拓扑面三种 `Convert` 重载，以及 `ConvertBatch`。支撑面成功只表示其几何验收通过；单面转换不会自动宣称相邻面 G1 通过。邻面重载要求输入确实共享拓扑边，再对重建面与邻面检查。CLI 目前只接受恰好一个裁剪 NURBS 面，不能据此宣称可直接替换整个多面装配模型。

`src/AnalyticRecovery.cpp` 先检查参数域、控制点、正权重及严格递增的不同节点，再调用内核恢复解析候选。候选不是最终结论：`src/BS2QuadCore.cpp` 还要求独立几何验收，必要时继续重建和验证裁剪面。空输入、自由曲面、损坏数据与内核异常分别返回失败状态。五个拟合器的 `Fit(NURBS)` 保留“恢复候选—独立界验收”的路径；`FitFromPoints` 则进入 `src/PointFitting.cpp`，二者证据范围不同。

### 二、有限点拟合的数值处理

有限点接口只约束给定点，不证明点间曲面。输入先逐点检查有限性，以点均值平移，再用均方根距离尺度归一化。尺度小于 `1e-12` 或非有限时拒绝，避免重复点被当成有效几何。协方差由完整的小规模对称 Jacobi 迭代求特征方向；平面至少需要二维展开，其他族要求三维展开，归一化特征值阈值为 `1e-12`。

线性求解使用带主元交换的消元，普通最小二乘通过法方程构造，并以相对主元门槛拒绝近奇异系统。这里没有计算并输出显式条件数，也没有使用完整 SVD；秩与主元检查不能表述为严格条件数保证。特别狭小、近退化的局部片仍可能被保守拒绝。

| 解析族 | 已实现的初值与几何约束 | 实用最少点数 |
| --- | --- | ---: |
| 平面 | 协方差最小特征方向作为法向，以点均值定位 | 3 |
| 球面 | 代数最小二乘求球心和半径，再可选几何细化 | 4 |
| 圆柱 | 遍历三个协方差方向，并增加二次型轴向初值；投影到轴的垂直平面拟圆 | 6 |
| 圆锥 | 由二次型解顶点，用异号特征值方向恢复轴与半锥角 | 10 |
| 环形圆环面 | 多轴初值，在径向距离与轴向坐标组成的子午面内拟合生成圆 | 12 |

圆柱没有把最大方差方向固定为轴线；这对短而宽或局部角度的点云尤其必要。圆锥顶点由二次型线性关系恢复，不以点云质心代替。圆环副半径来自生成圆，不采用径向标准差除以常数的近似。

可选细化采用数值差分雅可比和带阻尼的几何最小二乘，每组初值最多迭代 100 次，候选初值数有界。圆环仅接受环形情形；半锥角限制在 `1e-4` 与 `π/2−1e-4` 之间，半径等参数也设有尺度相关上限。这是有限搜索，不保证恢复所有可拟合点集。

### 三、最大世界残差是最终闸门

拟合阶段的均方误差不能掩盖离群点。最终验收重新读取已构造解析对象的实际世界坐标参数，逐点计算残差：平面为法向距离，球面为到球心距离与半径之差，圆柱为到轴距离与半径之差。令轴向坐标为 `z`、径向距离为 `ρ`，圆锥使用 `|ρ cosα−|z| sinα|`，环形圆环面使用 `|hypot(ρ−R,z)−r|`。

只有所有点的最大残差不超过指定容差，才发布曲面。`ValidateWorldCandidate` 的二次核对用于阻止反归一化后的球心或轴线舍入误差漏过验收。失败时输出句柄清空、拟合误差保持无穷大；成功后 getter 才更新为接受对象的参数。`GetFittingError()` 在有限点接口报告 RMS，接受条件仍是最大残差，详见五个 `src/*Fitter.cpp` 与 `include/PointFitting.h`。

### 四、裁剪、周期接缝与极点

`src/BS2QuadCore.cpp` 的 `RebuildTrimmedFace` 先深复制输入，避免添加参数曲线时修改调用方共享的边。它保留原有三维边和线框，替换支撑面，再为普通边添加目标面的二维参数曲线，即 pcurve，并检查同参数关系。周期接缝需要两条 pcurve；缺失任一分支即失败。

解析坐标架先与输入接缝和空间法向对齐。球面完整南北极的方向另行辨认，避免选错周期支撑面的互补区域。退化边不直接丢弃：代码先核对三维顶点位于解析极点，再由相邻非退化边的 pcurve 端点确定角区间，构造极点处的水平参数线。不能确定单一区间，或退化边没有映射到真实解析极点时，返回明确失败。

修复可能尝试反转线框的参数绕向及调用内核修复；之后仍要求线框数、边数不变，并通过拓扑有效性检查。面积使用 `Eps=1e-10` 的自适应积分核对；边与顶点容差不能超过 `1e-5 mm`。这些检查提高拒绝错误重建的能力，但不能替代任意复杂裁剪域的形式化等价证明。

### 五、几何证据与采样证据分开记录

`src/ImplicitCertificate.cpp` 以正权重、区间运算和 Bernstein 控制系数界，计算源 NURBS 整个参数域到目标解析支撑面的单向距离上界。当前有次数预算和目标族限制；无法形成有限上界时不能接受。该界不自动证明反向覆盖、裁剪边界或 G1。

`src/AccuracyValidator.cpp` 的边界检查采用双向“源点到目标边集合的最小距离，再取最大值”，每条普通边取 33 个样本，并计入修剪曲线端点。它不取所有边对距离的最大值。裁剪域另作双向内部采样分类，周期参数映射回有限 UV 窗口；原面与新面的法向在同一空间点对应比较。边界阈值固定为 `1e-5 mm`，不会随支撑面容差放宽。核心的邻面重载还要求共享输入边，使用 0.1° 有向法向角阈值；方向相反的邻面会失败。

`include/Common.h` 把支撑面、边界、法向、邻接、独立距离界分别设旗标。缺失或失败的项目不能以零误差表示通过。边界、内部与法向仍是有限采样检查，报告必须保留这个限定。

### 六、具体回归与真值来源

`tests/unit_tests/test_point_fitting.cpp` 直接以解析公式构造 11×9 个点，再施加位置 `(13,−7,5)`、轴向 `(1,2,3)` 的刚体坐标架。球与圆柱真值半径为 5，圆锥半锥角为 0.4，圆环主、副半径为 8 和 2。薄局部圆柱高度仅 0.06；测试同时核对轴向、半径与点投影残差。另有所有族的空、重复、共线、NaN 点拒绝，以及单个离群点不能被 RMS 平均掉的断言。

`WorldCoordinateRoundingMustNotBypassTheResidualGate` 使用 `1e12` 平移和精确球心坐标中的 `5/6`，要求在 `1e-6` 容差下拒绝不可准确存储的结果。`src/TestDataGenerator.cpp` 则先把解析曲面转换为有理 NURBS，再保形插结增加控制点，避免把普通圆周控制点网格误当成精确圆柱。

`tests/unit_tests/test_conversion_contract.cpp` 覆盖局部球、锥、环面以及完整闭合圆柱、球和环面的有效裁剪面；也检查带位置变换的输出与输入不被修改。`tests/unit_tests/test_validation_regression.cpp` 的窄突起落在采样列之间，要求独立界拒绝；非夹持高端点回归防止插结漏掉最后控制点；额外内孔、反向面及真实共享边上的 90° 折角分别验证边界与法向语义。

上述是可追溯的工程实现与回归断言，不构成新颖性结论、任意 CAD 模型完整支持或 SGK 兼容声明。噪声、极端病态局部片、复杂多面替换的覆盖率，仍须依赖额外数据与实际运行证据。
